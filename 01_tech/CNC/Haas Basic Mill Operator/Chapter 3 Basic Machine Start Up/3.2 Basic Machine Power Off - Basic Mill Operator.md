# Haas CNC Machine Shutdown & Maintenance Standard Operating Procedure (SOP)

This guide provides a comprehensive checklist and protocol for daily end-of-day shutdown and weekend machine preservation based on Haas certification standards.

---

## Daily End-of-Day Shutdown Procedure

### 1. Enclosure & Chip Removal
* **Frequency:** Clear chips multiple times during the day between part runs, and **always** before leaving at night.
* **Risk Prevention:** Never leave large piles of chips overnight—especially steel or iron—as they accelerate rust, degrade the enclosure, and can cause physical damage to way covers and moving parts.
* **Procedure:**
  1. Press `HANDLE JOG`.
  2. Jog the machine table around while using the wash-down hose to push chips off:
     * Machine table
     * Vises / Fixtures
     * Way covers
  3. Push all chips down into the bottom of the enclosure.
  4. Run the chip auger or conveyor (if equipped) while using the wash-down hose to push chips onto it, discharging them into the chip bin.

### 2. Coolant & Moisture Management
1. Press `EMERGENCY STOP`.
2. Use the compressed air gun to blow off standing coolant puddles from:
   * The machine table
   * Around the spindle exterior and active tool
   * Vises and fixturing
3. **CRITICAL WARNING:** **NEVER point the air gun directly UP into the spindle nose.** Compressed air can force chips, coolant, and fine contaminants past seals into the spindle bearings, severely reducing bearing lifespan.

### 3. Coolant Level & Concentration Check
1. **Check Level:**
   * Review the coolant level readout on the screen or manually check the sight gauge / coolant tank.
   * *Note:* If the machine was just running, allow time for coolant to drain back into the tank. Do **NOT** fill to the absolute brim.
2. **Refill Protocol:**
   * **NEVER add plain water alone.** Always add a pre-mixed solution of water and coolant concentrate.
   * Measure concentration using a **refractometer** before topping off to ensure the proper mix ratio. Adjust as directed by shop guidelines or supervisors.

### 4. Work Area Cleanup & Final Power Off
1. Return tools and measuring equipment to designated storage areas.
2. Clean up any liquid spills or oil drips on the floor around the machine.
3. Press `POWER OFF` on the operator panel.

---

## Weekend & Extended Shutdown Procedure (Friday Night Protocol)

In addition to all daily shutdown steps, perform the following before leaving the machine idle over the weekend or during extended breaks:

### 1. Rust Prevention Application
1. Open the machine enclosure doors.
2. Liberally apply shop-approved rust preventative spray/oil to all exposed, unpainted metal surfaces:
   * Way covers
   * Machine table surface and T-slots
   * Vises, chucks, and fixturing
   * Tool held in the spindle
3. Apply rust preventative to any external tools or toolholders loaded for upcoming jobs that are not currently inside the tool changer.

### 2. Main Utilities & Breaker Shutdown
1. Close the machine enclosure doors.
2. Press `POWER OFF` on the operator panel.
3. Switch off the main electrical circuit breaker on the back of the CNC cabinet.
4. Shut off the main compressed air supply valve connected to the machine.

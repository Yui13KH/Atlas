
# Machine Startup, Homing Sequences, & Operational Readiness: Technical Notes

## 1. Machine Power-On & Diagnostic Sequence

To bring a CNC mill online from a cold-start state, operators follow a precise hardware and software sequence to verify air pressure, electrical safety, and encoder reference points.

```
                  [ REAR POWER ] ──► Check Main Circuit Breaker (Normally ON)
                        │
                        ▼
                  [ AIR SYSTEM ] ──► Verify Air Pressure Gauge is in Spec
                        │
                        ▼
               [ PENDANT POWER ] ──► Press "Power On" -> System Diagnostics
                        │
                        ▼
               [ SAFETY CHECK ]  ──► Clear E-Stop & Cycle Enclosure Doors
                        │
                        ▼
                [ AXIS HOMING ]  ──► Press "Power Up" -> Sequential Axis Home
```

- **Main Circuit Breaker:** Located at the rear cabinet; usually left engaged unless complete shop isolation is required.
    
- **Pneumatic Inspection:** Confirm incoming air line pressure via the side pressure gauge. Low air pressure halts execution and generates an alarm; alert a supervisor if pressure is out of range.
    
- **Initial Diagnostics & Interlocks:**
    
    1. Pressing **Power On** triggers internal control diagnostics and defaults to an initial **E-Stop** alarm state.
        
    2. Cycle the enclosure doors so the control verifies interlock switch functionality.
        
    3. Disengage E-Stop (twist clockwise) and press **Power Up**.
        

## 2. Encoder Reference & Axis Homing Protocol

Homing establishes the machine's baseline coordinate system ($0,0,0$) by referencing the physical position encoders for all linear movement axes and the tool changer assembly.

- **Standard Homing Order:** $Z$-axis homes **first**, followed simultaneously by $X$ and $Y$.
    
    - _Kinematic Safety:_ Retracting the vertical spindle ($Z$) upward out of the cutting envelope prevents the tool from crashing into table fixtures during $X/Y$ traverse.
        
- **Manual vs. Automatic Homing:**
    
    - **Next-Gen Control (NGC):** Handled automatically via the **Power Up** button sequence.
        
    - **Classic Haas Control:** Requires clearing initial alarms with the **Reset** key multiple times before pressing **Power Up**.
        
- **Sequential Homing Override (Collision Prevention):**
    
    - If tall fixtures, long tooling, or complex setups risk collision during automatic homing, **do not run automatic homing**.
        
    - Require a supervisor to execute step-by-step, single-axis manual homing.
        

## 3. Pre-Operation Inspection & Preventative Maintenance

|**Subsystem**|**Inspection Protocol**|**Critical Operating Threshold**|
|---|---|---|
|**Table & Way Covers**|Inspect visual surfaces for chips, debris, or coolant buildup.|Must be fully cleared of chips prior to executing any job setup.|
|**Coolant Level**|Check control display readout via **Memory Mode**; cross-reference at rear tank.|Minimum **3/4 full** before starting production. Manual tank inspection is required if sensor is disconnected.|
|**Chip Catch Tray**|Inspect screen tray at the coolant tank entrance.|Must be cleared into the chip bin daily to prevent coolant starvation/overflow.|
|**Spindle Thermal Stability**|Run a designated **Spindle Warm-up Program** prior to initial cuts.|Gradually ramps up spindle RPM over several minutes to distribute lube and stabilize thermal expansion.|

## 4. Operational Motion Controls (Start / Stop Protocols)

```
                       ┌───────► CYCLE START  ──► Executes G-code Program
                       │
[ CONTROL STATE MANAGEMENT ] ──► FEED HOLD    ──► Pauses Axes / Spindle Stays ON
                       │
                       ├───────► RESET        ──► Aborts Program to Block 1
                       │
                       └───────► E-STOP       ──► Instant Override / All Hardware OFF
```

- **Cycle Start:** Begins or resumes automated G-code execution.
    
- **Feed Hold:** Pauses linear axis motion instantly while maintaining programmed spindle RPM. Used for visual inspections. Resumes directly via **Cycle Start**.
    
- **Reset:** Instantly halts axis motion and resets the active program back to the top (Line 1). _Not suitable for emergency motion override._
    
- **Emergency Stop (E-Stop):** Hardware-level panic button. Immediately cuts power to axis drives, spindle, and tool changer, regardless of mid-cut or tool-change status. Standard protocol in many facilities when leaving machines unattended during breaks or shifts.
    

## 5. Machine & Job Readiness Verification Checklist

Before pressing **Cycle Start** on a production run, operators must verify physical setup and control program parameters:

1. **Workholding Security:** Confirm vise or fixture is bolted tightly to the table $T$-slots and visually aligned.
    
2. **Part Location Stops:** Verify part stops are rigidly attached to the vise or fixture.
    
3. **Program Verification:** Press **Memory** to verify the correct active program number at the top of the display.
    
4. **Tooling & Materials:** Verify required cutting tools are loaded, undamaged, and mapped to the program's tool table, and ensure raw stock is staged adjacent to the cell.

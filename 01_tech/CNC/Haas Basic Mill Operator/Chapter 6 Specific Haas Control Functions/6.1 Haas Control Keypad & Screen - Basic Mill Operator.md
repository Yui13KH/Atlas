# Haas CNC Control Panel & Keyboard Layout Standard Operating Procedure (SOP)

This guide details the physical organization, display menus, operational modes, and manual motion controls of the Haas CNC control pendant based on Haas certification standards.

## 1. Overview of the Control Pendant

The pendant serves as the primary user interface to the Haas control computer. It features **132 keys** organized into **8 distinct functional sections**:

1. **Alpha Section**
    
2. **Numeric Section**
    
3. **Cursor Section**
    
4. **Function Section**
    
5. **Display Section**
    
6. **Mode Section**
    
7. **Jog Section**
    
8. **Override Section**
    

## 2. Detailed Breakdown of Keyboard Sections

### Alpha & Numeric Sections

- **Alpha Section:** Contains letters in alphabetical order, punctuation keys, and a `SHIFT` key.
    
- **Numeric Section:** standard calculator-style keypad with digits, decimal, space, `CANCEL`, and `WRITE/ENTER` keys.
    
- **Usage:** Used together to input program commands, parameters, and numeric offset values.
    

### Cursor Section

- Contains 8 directional navigation keys: `UP`, `DOWN`, `LEFT`, `RIGHT`, `HOME`, `END`, `PAGE UP`, and `PAGE DOWN`.
    
- Used to navigate through menus, tables, and program text lines.
    

### Function Section (Machine Setup Keys)

Located at the top of the keypad, these keys prepare the machine for setup and recovery:

- **`RESET`:** Clears alarms, clears highlighted text, and resets the control for operation. Must be pressed after releasing an `EMERGENCY STOP` to clear the e-stop state.
    
- **`POWER UP / ZERO RET`:** Automatically homes all machine axes and initializes system states at startup.
    
- **`TOOL RECOVER`:** Guides the operator through step-by-step automated recovery if a tool change is interrupted mid-cycle.
    
- **`F1` – `F4`:** Function-dependent keys assigned by the system depending on the current menu.
    
- **`TOOL OFFSET MEASURE` / `NEXT TOOL`:** Used during setup to set tool length offsets and cycle through carousel positions.
    
- **`TOOL RELEASE`:** Unclamps the tool currently held in the spindle (also accessible via a physical button on the spindle head).
    

## 3. Display Section (Screen Views)

The display keys control what information is rendered in the main upper screen quadrants:

- **`PRGRM` (Program):** Displays the active CNC program currently loaded in memory.
    
- **`POSNT` (Position):** Shows physical axis positions across different coordinate reference screens:
    
    - _Distance to Go:_ Displays remaining distance required to finish the current block (most useful for operators).
        
    - _Machine Position:_ Shows absolute position relative to machine home.
        
    - _Operator / Program Position:_ Shows positions relative to local reference points and active work offsets.
        
- **`OFFSET`:** Opens tables for **Tool Length Offsets** (tool overhang distances) and **Work Offsets** (part location relative to home).
    
- **`CURNT COMDS` (Current Commands):** Accesses system timers, macro variables, devices, calculators, and Advanced Tool Management (ATM).
    
- **`ALARM`:** Displays active alarms and system alarm history log.
    
- **`DIAGNOST` (Diagnostics):** Shows system parameters, feature diagnostics, maintenance logs, and I/O status.
    
- **`SETNG` (Settings):** System preferences menu used to customize control behavior and machining parameters.
    
- **`HELP`:** Contextual help menu. Typing a code (e.g., `G84`) and pressing `F1` searches full documentation directly on screen.
    

## 4. Mode Section & Program Management

The 6 primary Mode keys (left column) determine the operational state of the machine, while the adjacent 4 modifier keys (right columns) alter tasks within that mode:

|**Mode Key**|**Function**|**Associated Modifier Keys**|
|---|---|---|
|**`EDIT`**|Modify existing programs line-by-line.|`INSERT`, `ALTER`, `DELETE`, `UNDO`.|
|**`MEM` (Memory)**|Primary operational state for running production programs from memory.|`SINGLE BLOCK`, `DRY RUN`, `OPT STOP`, `BLOCK DELETE`.|
|**`MDI` (Manual Data Input)**|Scratchpad execution for entering and running immediate code commands without saving to memory.|Controls for turning coolant ON/OFF, manually indexing tool changer, or setting `HANDLE SCROLL`.|
|**`HANDLE JOG`**|Enables manual motion control using the handwheel.|Increment modifiers: `.0001"`, `.001"`, `.01"`, `.1"`.|
|**`ZERO RET`**|Automated homing mode.|`ALL`, `SINGL`, `G28`, `ORIGIN`.|
|**`LIST PROGRAM`**|File directory for internal memory, USB, and network drives.|`SELECT PROGRAM` (loads highlighted file into active memory), navigation arrows.|

- **Graphics View:** Within `MEM` mode, pressing `GRAPHICS` renders a visual toolpath simulation on screen prior to cutting metal.
    

## 5. Jogging & Manual Axis Motion

### Axis Selection & Handwheel

1. Press `HANDLE JOG`.
    
2. Select the axis to move in the Jog section (`X+`/`X-`, `Y+`/`Y-`, `Z+`/`Z-`).
    
3. Select travel increment:
    
    - **`.0001"` (0.001 mm)**
        
    - **`.001"` (0.01 mm)** — _Safest starting point for beginners to prevent accidental crashes_.
        
    - **`.01"` (0.1 mm)**
        
    - **`.1"` (1.0 mm)**
        
4. Rotate the manual jog wheel to move the chosen axis.
    

### Continuous Jogging (`JOG LOCK`)

1. Press `JOG LOCK` to activate continuous motion mode.
    
2. Press an axis direction key (e.g., `X+`). The axis moves continuously at the rate determined by the active jog increment key until `JOG LOCK` is pressed again or the axis hits software limits.
    
3. Alternatively, holding down an axis key continuously drives that axis until released.
    

## 6. Manual Auxiliary Controls & Overrides

### Peripheral Controls

- **Chip Conveyor Keys:** Manual control to start, reverse, or stop the chip auger/conveyor.
    
- **Coolant / P-Cool Keys:** Manual keys to toggle flood coolant and adjust Programmable Coolant nozzle position.
    

### Override Keypad Section

- **Rapid Overrides (`5%`, `25%`, `50%`, `100%`):** Safely reduces programmed rapid motion speed during program prove-outs.
    
- **Feed & Spindle Overrides:** Dynamically speeds up or slows down spindle speed and cutting feed rates.
    
    - **OPERATOR RULE:** Do not adjust Feed or Spindle overrides during production unless authorized by a supervisor, as unapproved adjustments can cause tool breakage or machine damage.
        
- **Spindle Manual Controls:** Manual keys to start, stop, or reverse spindle rotation.
    

## Quick Reference Summary

|**Task**|**Key Sequence / Action**|**Safety Rule**|
|---|---|---|
|**Clear Alarm / E-Stop**|Press `RESET`|Verify reason for stop before clearing.|
|**Load Active Program**|`LIST PROGRAM` $\rightarrow$ Highlight File $\rightarrow$ `SELECT PROGRAM`|Verify loaded file in upper-left window.|
|**Check Travel Remaining**|`POSNT` $\rightarrow$ Distance to Go|Stop if remaining distance exceeds visual gap.|
|**Safe Manual Jogging**|`HANDLE JOG` $\rightarrow$ Select Axis $\rightarrow$ Choose `.001"` increment|Avoid large increments near vises or fixtures.|
|**Prove-Out New Program**|`MEM` $\rightarrow$ `SINGLE BLOCK` = ON $\rightarrow$ Rapid Override = 25%|Keep hand near `FEED HOLD` during cuts.|

# Haas CNC Machine: Program Structure & First-Part Safety Standard Operating Procedure (SOP)

This comprehensive guide covers the essential components of a CNC milling program, key control panel features for safely proving out new programs, and sensory monitoring techniques during machining operations based on Haas certification standards.

## 1. CNC Program Structure & Key Elements

A CNC program relies on specific headers, codes, and human-readable text to control machine execution safely and accurately.

### Program Identification & Comments

- **Program Number (O-Number):** The unique identifier for every program file. It begins with the letter `O` followed by up to five numerical digits (e.g., `O00087`).
    
- **Comments:** Text enclosed in **parentheses `( )`**. The machine control ignores this text during execution. Comments provide critical operator information, including:
    
    - **Part Number & Revision Level:** (e.g., `Part # 20-9854 Rev C`). Always verify the program's revision matches the print before running.
        
    - **Target Machine & Options required**.
        
    - **Cutting Tool List:** Descriptions and designated tool numbers.
        
    - **Work Offsets:** Designated coordinate systems (e.g., `G54`, `G55`).
        
- **Program Stop (`M00`):** An explicit command that halts machine execution. The machine waits until the operator presses `CYCLE START` again. Used for mandatory mid-program manual tasks like part flipping, dimension checking, or clearing chips from blind pockets.
    

## 2. Safe Program Execution & Control Panel Functions

When proving out a program for the first part of a batch, you must slow down machine execution to prevent crashes.

### Key Modes & Controls

1. **Single Block Mode:**
    
    - Activated via the `SINGLE BLOCK` key on the keypad (verified by an on-screen icon).
        
    - Execution rule: The control executes **only one block (line) of code** per press of `CYCLE START`.
        
    - Purpose: Allows the operator or setup technician to step through code line-by-line to verify positions and movements safely.
        
2. **Rapid Override Controls:**
    
    - Dedicated keypad buttons (`5%`, `25%`, `50%`, `100%`) override `G00` rapid positioning speeds.
        
    - **First Run Protocol:** Set rapid override to **`25%`** (or lower) when proving out a new program.
        
    - **Production Note:** Always return rapid overrides to `100%` during production runs.
        
    - **CRITICAL WARNING:** **NEVER adjust Spindle Speed or Feed Rate overrides** unless instructed. Overriding programmed feed/speed rates can cause tool breakage, damaged workpieces, or machine damage.
        
3. **Distance to Go Display:**
    
    - Access by pressing `POSITION` and navigating to the `DISTANCE TO GO` screen.
        
    - Purpose: Shows the exact remaining distance each axis must travel to complete the current block.
        
    - **Safety Rule:** If the display shows remaining travel (e.g., `3.0 inches`) but the tool is already touching or nearly touching the workpiece, **STOP immediately**. Do not press `CYCLE START`; notify a supervisor.
        

## 3. Step-by-Step Program Execution & Verification Flow

When stepping through a program in **Single Block Mode** at reduced rapid speed:

1. **Tool Call Verification (`T_ M06`):**
    
    - Code calls the tool (e.g., `T1 M06`).
        
    - **Visual Check:** Visually compare the actual tool loaded in the spindle against the tool description listed in the header comments (e.g., confirming a 2-inch face mill is in the spindle, not a drill).
        
2. **$X$/$Y$ Axis Positioning:**
    
    - Code moves table to initial $X$/$Y$ coordinates.
        
    - Verify active work offset (e.g., `G54`) matches header comments.
        
3. **$Z$-Axis Approach & Tool Offset (`G43 H_ Z_ M08`):**
    
    - Applies tool length offset (`G43 H1`), turns spindle on, moves $Z$-axis down above the part (e.g., `Z0.1`), and turns on coolant (`M08`).
        
    - Check `DISTANCE TO GO` before the tool reaches the part.
        
    - **Coolant Override Toggle:** Press `COOLANT` to temporarily pause coolant flow to visually verify the gap between tool tip and workpiece.
        
    - **CRITICAL WARNING:** **Always turn coolant back ON** before executing lines where actual metal cutting occurs. Dry cutting damages tools and ruins parts.
        

## 4. In-Process Sensory & Load Monitoring

Once cutting begins, continuously monitor the machine using sight, sound, feel, and control meters:

- **Visual Monitoring:**
    
    - Verify coolant streams are aimed directly into the cutting zone and hitting tool tips.
        
    - Inspect machined surfaces for changes in surface finish (chatter marks, tearing).
        
- **Auditory Monitoring:**
    
    - Material cutting should produce a smooth, uniform, low tone.
        
    - High-pitched squealing, loud chatter, or abnormal banging indicates improper cutting parameters or dull tooling.
        
- **Tactile Monitoring (Vibration):**
    
    - Touch the machine enclosure to feel standard cutting vibration. Sudden increases or changes in vibration signal cutting issues.
        
- **Control Load Meters:**
    
    - Monitor the **Spindle Load** and **Axis Load** gauges on the control display.
        
    - Gradual load increases over time are normal due to tool wear.
        
    - **Spike Warning:** Rapid or sudden spikes in load values indicate imminent tool failure. Pause execution and notify a supervisor.

| **Setup Checks**     | Verify part number & drawing revision  | Header comments vs. engineering drawing                                  |

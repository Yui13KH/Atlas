
# CNC Motion Control, Coordinate Systems, & G-Code Fundamentals: Technical Notes

## 1. Machine Kinematics & The 3-Axis Coordinate System

A standard 3-axis CNC milling machine operates using three orthogonal linear axes ($X, Y, Z$) to control relative motion between the cutting tool (spindle) and the workpiece (table).

- **X-Axis (Side-to-Side Motion):** Moving left/right relative to the machine bed.
    
- **Y-Axis (Front-to-Back Motion):** Moving forward/backward across the table.
    
- **Z-Axis (Vertical Motion):** Controls the depth of the spindle. Moving down into the cut is **negative ($-Z$)**; moving up away from the workpiece is **positive ($+Z$)**.
    
- **Machine Coordinate System (MCS):** The fixed physical coordinate frame defined by the machine manufacturer. The absolute **Home Position** $(0,0,0)$ sits at the physical limit switches (typically top-right/rear for $Z$ home, or front-left depending on machine build). All motions away from Home calculate in negative machine coordinates.
    

## 2. Work & Tool Coordinate Registration (Offsets)

To execute G-code relative to a part rather than the physical machine frame, the control calculates offset vectors to bridge the gap between machine coordinates, part position, and tool lengths.

$$\text{Tool Tip Position} = \text{Spindle Head Position (MCS)} + \text{Work Offset} - \text{Tool Length Offset}$$

- **Work Coordinate System (WCS / Work Offset):** Defines the part's reference point (e.g., $G54$) relative to the Machine Home. For example, if a part corner sits $-29.65\text{ in.}$ in $X$, $-7.29\text{ in.}$ in $Y$, and $-22.73\text{ in.}$ in $Z$ from Home, these values represent the base reference offset.
    
- **Tool Length Offset (TLO):** Measures the physical length from the spindle face to the cutter tip.
    
- **Program Coordinates:** Once offsets are set, the display shifts to show positions relative to the workpiece $(0,0,0)$. Motion into the part displays in negative values; retraction displays in positive values.
    

## 3. Programming Architecture: G-Codes, M-Codes, and Letter Addresses

CNC instructions use a standardized alphanumeric syntax where preparatory codes (G-codes) govern geometry/motion, and miscellaneous codes (M-codes) handle machine hardware functions.

```
                  [ COMMAND TYPE ]  +  [ LETTER ADDRESS ]
                          │                    │
                          ▼                    ▼
                G01 / M03 / M06        X, Y, Z / S / T / F
```

- **G-Codes (Preparatory Functions):** Define _how_ the machine moves or behaves (e.g., linear interpolation, rapid traverse, canned cycles).
    
- **M-Codes (Miscellaneous Functions):** Act like digital switches for auxiliary hardware (e.g., spindle control, tool changers, coolant pumps).
    
- **Letter Addresses (Parameters):** Provide explicit numerical parameters for G/M commands:
    
    - `S` (Spindle Speed): Sets RPM (e.g., `S1000` = $1000\text{ RPM}$).
        
    - `T` (Tool Select): Specifies tool pocket number (e.g., `T2` = Tool #2).
        
    - `F` (Feed Rate): Specifies linear motion speed in inches/mm per minute (e.g., `F20` = $20\text{ IPM}$).
        

## 4. Fundamental Motion Commands

| **Code** | **Command Name**             | **Motion Trajectory**                                          | **Application**                                                |
| -------- | ---------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------- |
| **G00**  | Rapid Positioning            | Non-cutting, maximum machine traverse speed.                   | Moving tools safely above the part before or after cutting.    |
| **G01**  | Linear Interpolation         | Straight-line cutting motion at a programmed feed rate (`F`).  | Profiling, slotting, facing, and direct plunging.              |
| **G02**  | Circular Interpolation (CW)  | Clockwise arc/circular path at a controlled feed rate.         | Milling rounded corners, bore interpolation, circular pockets. |
| **G03**  | Circular Interpolation (CCW) | Counter-clockwise arc/circular path at a controlled feed rate. | Milling internal/external arcs and helical thread operations.  |

## 5. Sample Program Block Breakdown

G-Code

```
M06 T2          ; Tool Change: Load Tool #2 into the spindle
G00 Z2.0        ; Rapid Traverse: Move Z axis rapidly to 2.0 inches above part zero
M03 S2000       ; Spindle Control: Start spindle Clockwise at 2000 RPM
G01 X1.0 Y1.0 F20.0  ; Linear Feed: Cut in a straight line to (X1.0, Y1.0) at 20 IPM
```

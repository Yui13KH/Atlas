
# Manual Tool Touch-Off (Using a 1/4" Puck): Quick Reference Guide for New Operators

## Step-by-Step Procedure

- **1. Setup Reference Blocks:** Place a **1-2-3 block** firmly inside the vise to provide a flat, parallel reference surface.
    
- **2. Load Tool via Control:**
    
    - Navigate to the control, select **Machine** > **Jog**, and open the **TSM (Tool, Spindle, Movement)** window.
        
    - Select your tool (e.g., 1/2" drill or end mill), close the enclosure door, and press **Cycle Start** to call the tool into position.
        
- **3. Insert Tool into Spindle:** Open the door, hold the green **Release to Clamp** button on the spindle head, and load the tool.
    
- **4. Position the Puck:** Place the **1/4" precision puck** on top of the 1-2-3 block.
    
- **5. Jog Tool Down (Handwheel):**
    
    - Activate the **Handwheel** mode on the control.
        
    - Use the axis selector and feed rate dials to jog the tool down carefully (start fast, switch to a slow increment as you get close).
        
- **6. Find the Touch-Off Point (Puck Test):**
    
    - _If the tool is too high:_ Slide the puck underneath, then jog the tool down in **1,000th ($0.001"$) increments** until the puck can just barely slide underneath freely.
        
    - _If the tool is too low:_ Jog the tool up in $0.001"$ increments until the puck can slide underneath.
        
- **7. Set Length in the Control:**
    
    - Return to the control's **TSM window** and select **Measure Tool** > **Length Manually**.
        
    - Verify or enter **0.250"** (matching the 1/4" puck thickness) in the designated window.
        
    - Press **Set Length** to calculate and record the tool's length offset.
        
- **8. Verify Offsets:** Press the **Offset** button on the control and confirm that the newly generated length value matches your active tool in the offset table.


# Loading a G-Code Program via USB: Quick Reference Guide for New Operators

## Step-by-Step Procedure

- **1. Insert USB:** Plug your USB key into the CNC controller.
    
- **2. Open Program Manager:** Press the **Program Manager** button on the control.
    
- **3. Select USB Source:** Navigate to and select the **USB** drive option.
    
- **4. Choose Program:** Highlight the desired program file.
    
- **5. Copy File:** Press **Copy**.
    
- **6. Navigate to Memory (NC):** Select **NC** (internal memory) and open the target folder where you want to store the file.
    
- **7. Paste File:** Press **Paste** to transfer the program into the machine's memory folder.
    
- **8. Execute Program:** Select/highlight the program and press **Execute** to make it the active program.
    
- **9. Switch to Auto Mode:** Press the **Auto** button to switch the machine into automatic operating mode.
    
- **10. Run Program:** Press **Cycle Start** to begin machining.

# Program Simulation: Quick Reference Guide for New Operators

## Step-by-Step Procedure

- **1. Open Program Manager:** Navigate to the program manager on the control and highlight the program you want to test.
    
- **2. Open Program:** Press the **overwrite arrow key** to open the program in a new editing/viewing window.
    
- **3. Launch Simulation:** Select the **Simulation** option from the bottom menu to open the graphical toolpath display.
    
- **4. Check Top-Down View:**
    
    - Observe the toolpath from the top view.
        
    - Use the zoom-in and zoom-out tools to inspect the path.
        
    - Verify that the tool moves only where expected and stays within the correct boundaries.
        
- **5. Check Front View (Z-Level Verification):**
    
    - Toggle the simulation off and switch to the **front view** perspective.
        
    - Run the simulation again to check your **Z levels**.
        
    - Ensure the tool does not drop below safe heights, which would indicate a potential crash.
        
- **6. Ready for Dry Run:** Once both top and front view simulations are confirmed clean and correct, you are ready to move on to a dry run above the part.

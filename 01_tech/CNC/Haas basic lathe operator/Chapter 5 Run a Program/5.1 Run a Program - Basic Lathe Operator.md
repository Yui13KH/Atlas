# 🛠️ CNC Lathe: Operations & Programming Logic (Level 1)

### 1. Program Structure & Navigation

- **Loading:** Press `[MEMORY]` to view the active program.
    
- **The "O" Number:** Programs always start with the letter `O` followed by up to 5 digits (e.g., `O12345`).
    
- **Comments:** Anything inside `(parentheses)` is ignored by the machine.
    
    - _Best Practice:_ Always include the **Part Number** and a **Tool List** at the top.
        
    - _The "Pro" Move:_ Add a description every time a tool is called (e.g., `T0101 (Roughing Lathe Tool)`).
        

### 2. The "Safety First" Debugging Suite

- **Single Block Mode:** * The "Step-Through Debugger." The machine executes exactly **one line** per press of `[CYCLE START]`.
    
    - Use this to verify every single move before it happens.
        
- **Overrides**
    
    - **Rapid Overrides (`G00`):** Set to **5%** for the first run.
        
    - **Feed/Spindle Overrides:** Keep these at 100% usually, but keep your hand hovering over `[FEED HOLD]`.
        
- **Distance-to-Go:** **Crucial.** Look at the screen and compare the "Distance-to-Go" number with the actual physical gap between the tool and the part. If the screen says 50mm left but the tool is 10mm away, **STOP.**
    

### 3. G-Code Fundamentals

| **Code** | **Function**    | **Logic**                                                                                                                          |
| -------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **G00**  | Rapid Motion    | Fast move into position. **Never use for cutting.**                                                                                |
| **G01**  | Linear Feed     | Controlled motion for actual cutting.                                                                                              |
| **G54**  | Work Coordinate | Tells the machine where the "Part Zero" is. (Usually the face of the part).                                                        |
| **G96**  | **CSS**         | **Constant Surface Speed.** The spindle speeds up as the tool moves toward the center (X0) to keep the cutting physics consistent. |
| **G97**  | **Direct RPM**  | Spindle stays at a fixed speed (RPM). Use this for drilling or threading.                                                          |

> **Note on G96 vs G97:** Think of a record player. To keep the needle moving over the "music" at the same speed, the disc has to spin faster when the needle is near the center because the circumference is smaller. That’s `G96`.

### 4. M-Code Fundamentals (Machine Actions)

- **M03 vs M04 (Spindle Direction):**
    
    - **M03 (Clockwise):** Standard for 90% of tools.
        
    - **M04 (Counter-Clockwise):** Used for "left-hand" tools or when a tool is mounted upside down in the turret to push the cutting forces down into the machine bed (for extra rigidity).
        
- **M08 / M09 (Coolant):**
    
    - Turn on tool-by-tool.
        
    - **Warning:** If you use the "Coolant Override" to see through the glass during a dry run, **never** forget to turn it back on. Friction + No Coolant = Melted Tool.
        

### 5. Coordinate Logic (Polar Thinking)

- **X-Axis:** Diameter. (Negative = toward center, Positive = away).
    
- **Z-Axis:** Length. (Negative = into the part, Positive = away from the face).
    
- **Origin (0,0):** Typically the center of the part's face.
    

### 6. The "Golden Rules" of the First Run

1. **Don't assume; verify.** Never skip a line thinking "it should be fine."
    
2. **The Sound Test:** A good cut sounds like a constant hum. "Chatter" (high-pitched screaming) or loud banging means your Speeds/Feeds are wrong.
    
3. **Load Monitoring:** Watch the **Spindle Load** meter. It’s normal for it to go up during a heavy cut, but a sudden spike means the tool is dull or you’re pushing too hard.
    
4. **The "2-3 Parts" Rule:** Stay in Single Block for the first few parts. Only go to 100% "Auto" mode when the dimensions are coming out perfect and the sounds are consistent.

### Clarifications for your Notes:

- **Why M04?** You asked why we need counter-clockwise. In modern CNC lathes, many people mount tools **upside down**. This sounds weird, but it forces the cutting pressure _downwards_ into the heavy cast-iron bed of the machine rather than pulling _up_ on the turret. It prevents vibration (chatter).
    
- **G96 (Dynamic Speed):** You are 100% right. It’s based on the diameter. As the diameter (X) gets smaller, the RPM increases automatically to maintain a constant "Surface Feet Per Minute" (SFM). This ensures the finish looks the same from the outside of the part to the center.
    
- **G54 vs G55:** `G54` is your first work offset (Position A). `G55` is just a second "save slot" for a different position (Position B). You could have two different parts in the same machine and use `G54` for one and `G55` for the other.

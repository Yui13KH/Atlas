# CNC Lathe Mastery: Study Notes

### 1. The Turret and Axis Logic

- **The Turret:** This is the tool-carrying component. It moves along two primary axes: **X** and **Z**.
    
- **Z-Axis (Length):** Moves left and right. Think of this as the "depth" into the material.
    
- **X-Axis (Diameter):** Moves up and down. This controls the diameter of the part.
    
- **The Coordinates:** Moving **Down** in X or **Left** in Z results in **Negative** values. Moving **Up** or **Right** is **Positive**.
    

### 2. Coordinate Systems (Machine vs. Work)

- **Machine Coordinate System (MCS):** The machine's "Home" or "Zero" point. Usually located at the extreme **Top-Right** (Max X, Max Z).
    
- **Work Coordinate System (WCS):** This is for actual programming. We define the **Centerline** of the cylinder as **X0** and the **Face** of the part as **Z0**.
    

### 3. Setting Offsets (Calibration)

If you don’t set offsets, the machine is "blind" to where your raw material is.

- **Manual Z-Offset:** Rotate the piece, move the tool until it barely touches the face (skimming), then press **"Z Face Measure."**
    
- **Manual X-Offset:** Skim the outer diameter, measure the diameter with a caliper (kumpas), and enter that value into **"X Diameter Measure."**
    
- **Probing:** Modern machines use a sensor (Probe) to touch the tool and set these numbers automatically and with much higher precision.
    

> **Note on X-Axis Diameter:** Lathes display X as a **Diameter** value (2x the actual distance from the center). Why? Because mechanical drawings give you diameters, and you are cutting a rotating piece; moving the tool 1mm toward the center actually removes 2mm of material from the total diameter.

### 4. G-Codes vs. M-Codes

- **G-Codes (Geometry/Behavior):** Tell the machine **how** to move (straight, arc, fast, slow).
    
- **M-Codes (Machine/Binary):** Act as "On/Off" switches for hardware (spindle, coolant).
    

**Common Code Examples:**

- `T101`: Selects **Tool 1** and applies **Offset 1**.
    
- `M03`: Spindle **ON** (Clockwise).
    
- `M08 / M09`: Coolant **ON / OFF**.
    
- `G00`: **Rapid Motion** (Move as fast as possible to a point; do NOT use this for cutting).
    
- `G01`: **Linear Interpolation** (Move in a straight line at a specific speed to cut).
    

---

### Q: Why Circular Motion (`G02 / G03`)?

**Answer:** You use these to create **radii** (rounded corners) or **fillets**.

- `G02`: Clockwise Arc.
    
- `G03`: Counter-Clockwise Arc.
    
- If you tried to make a curve using only straight lines (`G01`), the corner would look like a "staircase." Circular interpolation makes it perfectly smooth.
    

### Q: What is Feedrate (`F`), and is RPM irrelevant?

**Answer:** This is a crucial concept. On a lathe, we almost always use **Feed per Revolution** (e.g., `F0.005` means move 0.005 inches for every 1 full turn of the part).

- **Is RPM irrelevant?** No, but by using `mm/rev` or `in/rev`, the machine ensures the **cut quality stays exactly the same** regardless of how fast the spindle is spinning.
    
- If the RPM slows down, the tool slows down. If the RPM speeds up, the tool speeds up. This keeps your "chip thickness" constant, which protects your tool from breaking.

### Basic Program Block Template:

G-Code

```
T101 ;             (Select Tool 1)
G97 M03 S2000 ;    (Spindle on CW at 2000 RPM)
G00 X4.25 Z0.1 ;   (Rapid move to safe start point)
G01 Z-1.0 F0.005 ; (Cut straight to 1 inch deep at 0.005 feed per rev)
G00 X5.0 Z5.0 ;    (Rapid move away to a safe spot)
M30 ;              (End Program)
```

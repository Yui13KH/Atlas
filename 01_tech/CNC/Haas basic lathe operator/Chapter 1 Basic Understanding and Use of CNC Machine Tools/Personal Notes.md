
# CNC Simulation Stack (Free/Open Source)

1. **NC Viewer (Web):** Fast G-code backplotting. Use for "sanity checks" on coordinate math.
2. **CAMotics (Desktop):** Volumetric simulation. Use to visualize material removal and detect crashes.
3. **FreeCAD (Desktop):** Full-service CAD/CAM suite. Use to bridge the gap between "Designing a part" and "Generating the code."

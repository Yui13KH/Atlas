# Chapter 6: The Haas Control Interface

The Haas keypad is divided into **8 functional sections**. Understanding these is like learning the hotkeys of a new IDE.

### 1. Alpha Section

- **Layout:** A-Z in alphabetical order.
    
- **Usage:** Writing comments, naming programs, and manual G-Code entry.
    

### 2. Numeric Section

- **Layout:** Standard Numpad.
    
- **Usage:** Entering coordinates, feed rates, and tool numbers.
    

### 3. Cursor Section

- **Navigation:** 4 Arrows, `Page Up/Down`, `Home`, and `End`.
    
- **Logic:** Used to scroll through code or navigate multi-page offset tables.
    

### 4. Function Section

| **Key**                      | **Logic**                                                                                                                                                                        |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reset**                    | Clears alarms and resets the control. The "Escape" key of the machine.                                                                                                           |
| **Power Up/Restart**         | Automatic zeroing of all axes on startup.                                                                                                                                        |
| **F1-F4**                    | Context-sensitive keys (like `Alt` or `Cmd` modifiers).                                                                                                                          |
| **Tool Offset Measure**      | Records the length of the current tool into the offset table.                                                                                                                    |
| **Next Tool / Tool Release** | Cycles the turret or manually releases a tool from the spindle.                                                                                                                  |
| **part zero set**            | used to automatically set the work coordinate offsets (G54–G59) by recording the current position of the machine's spindle/tool (X, Y, or Z) as the reference point for the part |
|                              |                                                                                                                                                                                  |

### 5. Display Section (The "View" Layer)

- **Program:** View active G-Code.
    
- **Position:** Real-time X, Y, Z coordinates.
    
- **Offset:** The "Data Table" for tool geometry and work zero (`G54`).
    
- **Current Commands:** The "Live Debugger" (Loads, Macro variables, Timers).
    
- **Alarms / Diagnostics:** Error logs and hardware status.
    

### 6. Mode Section (The "State" Layer)

- **Edit:** The Code Editor. Use this to `Insert`, `Alter`, `Delete`, or `Undo`.
    
- **Mem (Memory):** Production Mode. This is where you run programs.
    
    - **Graphics:** The "Sandbox." Runs a visual simulation without moving the axes.
        
- **MDI:** Manual Data Input. The "Live Console" for executing single commands.
    
- **Handle Jog:** Transfers control to the physical jog wheel.
    
    - **⚠️ Safety Tip:** Stick to `.001` or `.01` increments. Using `.1` is like driving a car at 100km/h in a parking lot—you _will_ crash.
        
- **List Prog:** File Explorer (USB, Hard Drive, Internal Memory).
    

### 7. Jog Section (Manual Movement)

- **Axis Keys:** Select `X`, `Y`, or `Z` before spinning the wheel.
    
- **Jog Lock:** "Cruise Control" for manual movement.
    
- **Chip Controls:** Manual control for the chip conveyor (`Fwd`, `Stop`, `Rev`).
    
- **Coolant Controls:** `Clnt Up/Down` for adjusting nozzle aim.
    

### 8. Override Section (Live "Tweaking")

- **Spindle/Feed Overrides:** Adjust speed in 10% increments while the program is running.
    
- **Rapid Overrides:** Hard-limit the `G00` speed (5%, 25%, 50%, 100%).
    
- **Spindle Controls:** Stop or Start the spindle manually during a pause.
    

---

### Personal Dev Notes on UI Logic

- **Visualizer First:** Always run a program in **Graphics Mode** before **Memory Mode**. It's the "Dry Run" before deployment.
    
- **Reset is God:** If the machine makes a sound you don't like, or if you're panicking—hit **Reset**. It kills all motion immediately.
    
- **Origin Points:** `Zero Return` is like "Rebooting" the axis coordinates to the factory home position.
